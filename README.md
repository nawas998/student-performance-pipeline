# Student Performance Engineering & Analytics Pipeline

## 📌 Project Overview
This project satisfies **Project 1** requirements of my Big Data Career Portfolio. It models an end-to-end data pipeline that automates synthetic data generation, fixes data anomalies (duplicates/missing entries), and renders analytical dashboard graphics.

## 📁 Repository Structure
* **data/** -> `student_performance.csv` (The cleaned data matrix)
* **plots/** -> `subject_averages.png` & `attendance_impact.png` (Data visualizations)
* `README.md` -> Detailed project system documentation
* `analytics_engine.py` -> Core Python pipeline script

## 🛠️ Technology Stack
* Pure Python 3.x (File I/O, control loops)
* Matplotlib (Visual graphics generation)
